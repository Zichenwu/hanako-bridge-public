# Hanako Bridge

Desktop companion (Tauri 2 + Rust) that lets a cloud-hosted Hanako assistant work with files in folders
the user explicitly authorizes on their own computer. Every write, preview and upload is confirmed on
that computer; the server never sees absolute paths.

This repository is an automatically generated, history-less build mirror. It contains source sufficient
to build installers; design documents are maintained elsewhere. Builds require the repository secret
`HANAKO_DEFAULT_HUB_URL` (https URL of the Hanako hub).
